📦 Sales Analysis Project
This project analyzes the sales and profit data from the file Sale Dataset - File (3).csv. It helps to understand which products are selling the most and where the business is making a profit.

📝 About the Project
I have used Python to explore a dataset containing 4,115 sales records. The analysis covers different countries, product categories, and customer types.

📊 Dataset Features
The file Sale Dataset - File (3).csv includes:

Customer Names: Who is buying our products.

Locations: City, State, and Country.

Products: Categories like Furniture and Office Supplies.

Numbers: Cost, Sales, Profit, and Quantity.

🛠️ How to Run
Download the Sale Dataset - File (3).csv file.

Install Python and the Pandas library:

Bash
pip install pandas
Run the analysis script to see the results.

💡 Key Results
Top Products: Identified the most popular items.

Profit: Calculated the total profit across different regions.

Segments: Found out if most customers are individuals or big companies.
